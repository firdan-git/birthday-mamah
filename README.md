# Website Ulang Tahun untuk Mamah

Website hadiah digital untuk ulang tahun ke-58 Mamah: album kenangan, surat cinta digital, dan buku tamu dengan update realtime. Terdiri dari 5 halaman: Beranda, Tentang Mamah, Galeri, Buku Tamu, dan Doa.

Dibuat dengan HTML5, CSS3, dan JavaScript murni (tanpa framework). Buku tamu menggunakan Supabase.

## Cara Menjalankan Website Secara Lokal

Pilih salah satu cara berikut:

**Opsi 1 — VS Code (paling mudah)**

1. Install extension **Live Server** di VS Code.
2. Klik kanan file `index.html` → **Open with Live Server**.

**Opsi 2 — Python**

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000` di browser.

**Opsi 3 — Node.js**

```bash
npx serve .
```

> Membuka `index.html` langsung (double-click) juga bisa untuk preview, tetapi menjalankan lewat server lokal lebih disarankan.

## Cara Mengganti Foto

Foto yang ada sekarang: `mamah_1.jpg` (hero), `mamah_2.jpg` (Tentang Mamah), dan `mamah_3.jpeg` s.d. `mamah_16.jpeg` (galeri). Format `.jpg` dan `.jpeg` sama-sama didukung.

1. **Mengganti isi foto** — timpa file di `assets/images/` dengan **nama file yang sama**, tidak perlu ubah kode.
2. **Menambah foto baru ke galeri** — taruh file di `assets/images/` lalu tambahkan satu baris pada `CONFIG.galeri` di `script.js`:

```js
{ src: "assets/images/mamah_17.jpeg", caption: "Keterangan foto" },
```

3. Foto hero dan halaman Tentang bisa diarahkan ke file lain lewat `CONFIG.heroImage` dan `CONFIG.aboutImage` di `script.js`.
4. Ukuran yang disarankan: rasio potret 4:5 (atau bebas), kompres di bawah ±500 KB agar loading tetap cepat.

## Cara Mengganti Nama, Usia, Tanggal, dan Ucapan

Buka `script.js`, bagian `CONFIG` paling atas:

```js
const CONFIG = {
  namaMamah: "Mamah",
  usia: 58,
  tanggalUlangTahun: "28 Agustus 2026",
  ...
};
```

- `namaMamah` — panggilan untuk Mamah (muncul di judul, navbar, footer)
- `usia` — angka usia (muncul di judul, badge, dan footer)
- `tanggalUlangTahun` — tanggal yang tampil di hero dan footer
- `surat` — isi "Surat dari Anak". Isi dengan array paragraf, contoh:

```js
surat: [
  "Selamat ulang tahun ke-58, Mamah.",
  "Terima kasih untuk semuanya."
],
```

Jika dibiarkan `null`, isi surat diambil dari teks yang tertulis langsung di `index.html` (bagian `id="surat"`), jadi bisa juga diedit di sana.

- Paragraf "Tentang Mamah", kartu doa, dan teks footer bisa diubah langsung di `index.html`.
- Musik latar: taruh file lagu pilihanmu di `assets/music/`, lalu arahkan `CONFIG.musicFile` di `script.js` ke nama file tersebut (saat ini: `POTRET - Bunda.mp3`). Format yang didukung: MP3.
- Di halaman **Galeri**, menekan salah satu foto akan membuka slideshow otomatis: lagu mulai diputar dan foto berganti sendiri setiap 5 detik dengan transisi slide halus (bisa juga digeser manual dengan tombol panah, titik navigasi, atau swipe di layar sentuh). Kecepatan pergantian bisa diubah lewat `CONFIG` → `SLIDE_DELAY` (dalam milidetik) di `script.js`.

## Cara Menghubungkan Supabase (Buku Tamu)

Tanpa Supabase, buku tamu tetap berjalan dalam **mode demo** (pesan hanya tersimpan di browser, tidak sync antar perangkat). Supabase diperlukan agar ucapan tersimpan online dan muncul realtime di semua perangkat.

1. Buat akun/project baru di [supabase.com](https://supabase.com).
2. Buka **SQL Editor**, jalankan SQL berikut:

```sql
create table birthday_messages (
  id bigint generated by default as identity primary key,
  nama text not null,
  ucapan text not null,
  created_at timestamptz not null default now()
);

alter table birthday_messages enable row level security;

create policy "buku_tamu_bisa_baca"
  on birthday_messages for select
  to anon, authenticated
  using (true);

create policy "buku_tamu_bisa_kirim"
  on birthday_messages for insert
  to anon, authenticated
  with check (true);

alter publication supabase_realtime add table birthday_messages;
```

3. Buka **Project Settings → API**, salin **Project URL** dan **anon public key** (jangan gunakan service role key).
4. Buka `script.js`, isi dua konstanta paling atas:

```js
const SUPABASE_URL = "https://xxxxxxx.supabase.co";
const SUPABASE_ANON_KEY = "eyJhbGciOi...";
```

5. Refresh website. Buku tamu kini tersimpan ke Supabase, dan ucapan baru dari perangkat lain akan muncul otomatis (realtime) tanpa reload.

> Jika perintah `alter publication` di langkah 2 gagal, aktifkan realtime lewat dashboard: **Database → Replication → birthday_messages → aktifkan**.

## Struktur Tabel Supabase

Tabel `birthday_messages`:

| Kolom | Tipe | Keterangan |
|---|---|---|
| `id` | bigint (identity) | Primary key, dibuat otomatis |
| `nama` | text | Nama pengirim (wajib, maksimal 60 karakter) |
| `ucapan` | text | Isi ucapan (wajib, maksimal 500 karakter) |
| `created_at` | timestamptz | Waktu kirim, otomatis terisi `now()` |

Keamanan: Row Level Security (RLS) aktif — pengunjung anonim hanya boleh **select** dan **insert**, tidak bisa mengubah atau menghapus data.
